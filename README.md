# رفيق الحفظ 📖

برنامج لحفظ القرآن الكريم يعمل في المتصفح (على الموبايل أو الكمبيوتر):

- **خطة حفظ يومية**: حفظ جديد + مراجعة قريبة + مراجعة بعيدة + نقاط الضعف.
- **التسميع بالصوت والنص مخفي**: تقرأ والبرنامج يسمعك، وكل كلمة تقولها صح تظهر في مكانها.
- **حفظ الأخطاء تلقائياً**: الكلمة التي تخطئ فيها أو تسقطها أو تنساها (زر "نسيتها") أو تتردد فيها تُسجَّل في "نقاط الضعف".
- **تذكير دائم بنقاط الضعف**: تظهر لك للمراجعة غداً، ثم بعد يومين، ثم ٤، ثم ٧، ثم ١٥، ثم ٣٠ يوماً. كل مرة تقرأها صح تتباعد، ولو أخطأت ترجع من الأول.
  ووقت التسميع يظهر خط برتقالي تحت الكلمة المخفية التي أخطأت فيها سابقاً حتى تركّز عندها.

## المميزات

| الشاشة | ماذا تفعل |
|---|---|
| **اليوم** | مهام اليوم بالترتيب: نقاط الضعف المستحقة ← الحفظ الجديد ← المراجعة القريبة ← المراجعة البعيدة، مع إحصاءات وأيام متتالية. |
| **الحفظ الجديد** | عرض الورد كاملاً مع الاستماع لكل آية وتكرارها (الحصري، المنشاوي، العفاسي…)، ثم التسميع. يُعتمد الحفظ فقط لو حققت نسبة الإتقان (٩٠٪ افتراضياً). |
| **التسميع** | النص مخفي، يُكشف كلمة كلمة مع ما تقوله. الألوان: أحمر = خطأ/سقط، بنفسجي = نسيتها، برتقالي = تردد ثم صححت. لو البرنامج فهمك غلط اضغط على الكلمة لتصحيحها. زر ↩ للتراجع. |
| **نقاط الضعف** | كل الآيات التي فيها أخطاء، مع الكلمات مظللة وعدد الأخطاء وموعد المراجعة القادم ومراحل التثبيت. |
| **تسميع حر** | سمّع أي سورة أو مقطع خارج الخطة. |
| **الخطة** | سورة البداية، الاتجاه (من الناس نزولاً أو من الفاتحة صعوداً)، المقدار اليومي (آيات / أسطر / صفحات)، أيام الحفظ، المراجعة، السور المحفوظة سابقاً، التذكير، تقدير موعد الختم، ونسخة احتياطية. |

## التشغيل

البرنامج ملفات ثابتة (HTML/CSS/JS) بدون أي مكتبات. يحتاج فقط خادم ويب لأن المتصفح لا يسمح بالميكروفون من ملف محلي:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### النشر على GitHub Pages (لفتحه من الموبايل)

1. من إعدادات المستودع: **Settings → Pages → Source: GitHub Actions**.
2. ادمج الفرع في `main`، وسيُنشر تلقائياً على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.
3. من الموبايل افتح الرابط في Chrome واختر **"إضافة إلى الشاشة الرئيسية"** ليعمل كتطبيق (ويعمل بدون إنترنت ما عدا التعرف على الصوت والاستماع).

## ملاحظات مهمة

- **المتصفح**: التعرف على الصوت يعمل في **Chrome** و**Edge** و**Safari** (iOS 14.5+). Firefox لا يدعمه، وفيه يمكنك التسميع اليدوي (زر "قلتها صح" / "نسيتها").
- **الإنترنت**: التعرف على الصوت في Chrome يتم عبر خوادم Google، فيحتاج اتصالاً.
- **الدقة**: التعرف على الصوت ليس مثالياً مع التجويد والمدود. البرنامج متسامح مع اختلاف الرسم العثماني عن الإملائي (الصلوة/الصلاة، العلمين/العالمين…)، ومتشدد في زيادة أو حذف واو العطف (أحد ≠ واحد). لو أخطأ في الحكم اضغط على الكلمة لتصحيحها.
- **في بداية المقطع** يمكنك قول الاستعاذة والبسملة أو البدء من الآية السابقة؛ لا تُحسب أخطاء.
- **البيانات** محفوظة على جهازك فقط (localStorage). استخدم "تصدير" في صفحة الخطة لعمل نسخة احتياطية.
- **التذكير**: إشعارات المتصفح تعمل والبرنامج مفتوح أو مثبّت. للتذكير المضمون استخدم زر "أضف تذكيراً يومياً للتقويم".

## البنية

```
index.html            الواجهة
css/style.css         التصميم (يدعم الوضع الليلي)
js/app.js             الشاشات والتنقل والتذكير
js/quran.js           تحميل المصحف، التطبيع، مطابقة الكلمات
js/matcher.js         محرك التسميع: مطابقة ما تقوله بالنص وتحديد الأخطاء
js/speech.js          التعرف على الصوت (Web Speech API)
js/plan.js            الخطة اليومية ونقاط الضعف (التكرار المتباعد)
js/store.js           حفظ البيانات محلياً
data/quran.json       نص المصحف بالرسم العثماني
sw.js                 العمل بدون إنترنت
tests/                اختبارات محرك التسميع: npm test
```
